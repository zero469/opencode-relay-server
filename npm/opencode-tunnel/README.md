# opencode-tunnel

Tunnel client for OpenCode Anywhere - access your local OpenCode instance from anywhere.

## Installation

```bash
npm install -g opencode-tunnel
```

## Usage

```bash
# Start tunnel (interactive menu)
opencode-tunnel

# Start with specific port
opencode-tunnel start -port 4096

# Check status
opencode-tunnel status

# Re-pair device
opencode-tunnel pair

# Logout
opencode-tunnel logout
```

## Supported Platforms

- macOS (Intel & Apple Silicon)
- Linux (x64 & arm64)
- Windows (x64)
